Model & prototype details

The default preview plays a lightweight set of prepared portrait frames. It starts automatically and doesn’t load the neural model. A custom experiment restores as a still image until you choose advanced editing. Reset to REIGN removes that account’s saved experiment from this browser.

Advanced editing uses LP-Distilled 0.1 to render 256 × 256 frames from your crop, pose, and expression controls. It downloads the model and ONNX Runtime from this site. WebGPU is used when supported; CPU rendering can take several seconds per frame. Closing the editor or leaving the page releases the model.

Between completed neural frames, the editor estimates movement and blends intermediate images. This smooths playback without speeding up the model. Fine details can still distort during turns or expressions. This Lab uses a separate model from Apple’s research and does not reconstruct a full 3D head.
