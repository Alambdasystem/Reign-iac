# REIGN pose image clarity review
This prototype does not change the live avatar. LP-Distilled generates native
256x256 images, not genuine 512px detail.

Dispatch the manual REIGN portrait clarity pilot workflow to download pinned
weights, generate a small pose set and upload unmodified contact sheets with
quality reports. Any blurry pose is rejected; candidates never deploy directly.
Automated high-frequency sharpness is not a substitute for human inspection
of eyes, teeth, hair, skin, shape or transitional ghosting.
Review every neural frame at native size and the actual full-screen Android
size, and review transitions before approving a separate renderer integration.
Do not lower sharpness thresholds just to pass. The original higher-resolution
portrait remains the idle fallback. No user photo or microphone access is needed.
